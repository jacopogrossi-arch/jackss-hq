# Logo Inverso — definitivo (10/11/2026)

| File | Uso |
|---|---|
| `inverso-logo.svg` | Logo crema (#EDE6D6) su nero, vettoriale: si ingrandisce senza perdere qualità |
| `inverso-logo-trasparente.svg` | Stesso logo senza sfondo, da sovrapporre a foto e video |
| `inverso-logo.png` | Immagine pronta per CapCut / Canva |
| `origine.svg` | Il logo di prima, da cui parte il disegno |
| `logo.py` | Rigenera `inverso-logo.svg` da `origine.svg` (`python logo.py`) |

**Cosa cambia rispetto a prima:** la I è un numero romano (due linee sottili staccate sopra e sotto), lo spazio tra le lettere è uguale ovunque e più stretto (20). Il resto del disegno è identico.

Scartati: E specchiata, versioni con font nuovi (Cormorant, Bodoni, Cinzel, Playfair). Prove in `videos/04-identita/logo-prove/` (solo locale).
