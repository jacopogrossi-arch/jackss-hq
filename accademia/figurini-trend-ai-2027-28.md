# Figurini — Trend A/I 2027-28

Un figurino menswear per ognuno dei 3 temi. Progetto: `progetto-trend-ai-2027-28.md`. Preparato l'08/10/2026.

**Workflow (lo stesso di After Hours, `outfit-after-hours.md`):**
1. **Flat B/N** su ChatGPT, **un capo per prompt**, con le pieghe ben marcate
2. **Ricalco a mano** in Procreate sul figurino base (`img-cinque-giacche/figurino-base-fronte.png`). Se le proporzioni non tornano: Trasforma → Distorsione, mai rigenerare il flat
3. **Colore** su ChatGPT con il prompt in fondo, allegando sempre `img-cinque-giacche/giacca2-outfit-FINALE.png` come riferimento di stile ("sembra colorato in Procreate")

Basta il fronte: la consegna chiede un figurino per tema, non fronte/retro.

File immagine in `img-trend-ai/` con nomi `onlife-flat-giacca-BN`, `onlife-outfit-FINALE`, ecc.

## Prompt flat B/N (template)

```
Technical fashion flat drawing of ONE garment only: [CAPO]. Laid flat, front view, no body, no mannequin, no other garments. Black and white line drawing only: clean black outlines, stitching as fine dashed lines, and the drape folds drawn clearly as confident lines so they can be traced by hand. No color, no grey fill, no shading, no hatching, no texture. Plain white background, no text, no labels. Vertical format, garment centered and filling the frame.
Details: [DETTAGLI]
```

## Prompt colore (step 3)

Allegare il figurino ricalcato + `img-cinque-giacche/giacca2-outfit-FINALE.png`.

```
This is a simple coloring task on this exact line drawing — nothing else. Do not add, remove, or redraw any linework — treat all lines as fixed and untouchable. The second image is only a style reference for the level of coloring.

Step 1: fill flat, matte base colors — [COLORI].

Step 2: on top of the flat color, add a simple airbrush pass for shadow and light only — dark shadow directly under/beside each existing fold line, light highlight directly above/beside it, following exactly the lines already drawn. Nothing invented beyond that: no extra texture, no grain, no smooth photographic gradient, no shine/gloss.

Keep all linework fully visible on top of the color. Result must read as a colored drawing, not a rendered illustration. Background stays clean white.
```

Per [COLORI] incollare la lista HEX del tema, in inglese: es. `nylon jacket #2B2829 with light grey #6A6668 along the folds, orange lining #E8692B visible at the open collar, hoodie #8E8C87, corduroy trousers #BFA58F, sneakers #E3DDCF`.

**Codici Pantone per la moodboard tecnica:** HEX → app **Pantone Connect** → "Trova corrispondenza" → TCX più vicino. Non inventarli.
